# Family Tasks LLM

Family task manager: any family member can add a shared task (due date,
owner, description, and when to be reminded). Built as the running project
for Lecture 1's "Your First LLM App" assignment — grows over the course.

A later stage will scan email for task-shaped content and suggest tasks
from it.

## Status

Repo scaffold only — assignment exercises (hosted LLM call, local
open-source model, file-based exercise) not yet implemented.
